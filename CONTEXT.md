# Drum Pattern Toolkit — Project Context for Claude Code

## What this is

A curated set of MIDI drum patterns for scratch-track production, designed for mix-and-match assembly in REAPER. The patterns are organized as instrument layers (kick, hi-hat, snare) that stack, plus complete genre gestures and fills.

The project was designed in conversation between Dan O'Donnell and Claude. This document captures the design rationale so Claude Code can set up the repository properly.

## Core design decisions

### Structure by function, not genre
Genres overlap at the beat level. The primary axis is what the pattern *does* (drives, swings, lays back, fills, transitions). Genre labels are tags, not the organizing principle.

### Layers, not complete beats
Kick/snare patterns, hi-hat patterns, and snare variations are separate MIDI files. You mix and match — drop a reggae one-drop kick under a straight eighth hi-hat, swap the hat for a shuffle, and you've got different feels from the same components. This is how drummers think about it.

### Genre gestures are the exception
The "genre gestures" category contains complete multi-instrument patterns because the *combination* is what makes them recognizable (e.g., reggae one-drop needs the empty beat 1 + kick/rimclick on 2-4 + upbeat hats together to read as reggae).

### Fills are single instances
Layer patterns loop (2 bars each). Fills are one-shot: they occupy the end of a bar and resolve with crash+kick on the downbeat.

### The generator script is the source of truth
All MIDI files are generated by `build_drum_toolkit.py` using the `mido` library. Patterns are defined as tick/pitch/velocity/duration tuples. Modifying or extending the toolkit means editing the script and re-running.

## Files included

- `build_drum_toolkit.py` — Generator script. Run with `python3 build_drum_toolkit.py`. Requires `mido` (`pip install mido`).
- `DRUM_TOOLKIT_README.md` — Full documentation: pattern descriptions, suggested pairings, GM drum map, technical details.
- `midi/` — 43 generated MIDI files across 6 categories (kick, hihat, snare, genre, fill, jazz).

## Patterns in the set

### Kick patterns (10)
- kick_01: Basic 1-3 backbeat
- kick_02: Anticipated 4 (1, 3, 3+)
- kick_03: Pushed 2 (1, 2+, 3)
- kick_04: Driving (1, 2+, 3, 4+)
- kick_05: Four on the floor
- kick_06: Half-time (1 only)
- kick_07: One-drop / reggae (2, 4)
- kick_08: Dotted quarter / cross-rhythm (1, 2+, 4)
- kick_09: Basic waltz (3/4)
- kick_10: Country waltz (3/4)

### Hi-hat patterns (10)
- hh_01: Straight 8ths closed
- hh_02: Straight 16ths closed
- hh_03: Quarter notes
- hh_04 (x3): Shuffle at 55%, 60%, 67% swing ratios (60% ≈ "Get Back" feel)
- hh_05: Open on upbeats (disco/new wave)
- hh_06: Upbeats only (ska)
- hh_07: Accented 16ths (funk/Motown)
- hh_08: Ride quarter notes

### Snare variations (4)
- snare_01: Full hit 2-4
- snare_02: Rimclick 2-4
- snare_03: Ghost notes on e's and a's (funk)
- snare_04: Half-time, snare on 3 only

### Genre gestures (7)
- genre_01: Reggae one-drop (complete)
- genre_02: Reggae steppers (complete)
- genre_03: Son clave 3-2 (2-bar, rimclick)
- genre_04: Son clave 2-3 (2-bar, rimclick)
- genre_05: Tresillo as kick pattern (the most versatile single pattern in the set)
- genre_06: Bossa nova
- genre_07: Samba surdo

### Fills (9)
- fill_01: 16th descending toms (standard rock)
- fill_02: Triplet descending toms
- fill_03: Snare roll 16ths with crescendo
- fill_04: Kick-snare alternating 16ths
- fill_05: Crash setup (minimal punctuation)
- fill_06: Reggae high-tom fill, 1 beat (Carlton Barrett-style) **← built from feel, not transcription; may need adjustment**
- fill_07: Reggae high-tom fill, 2 beat **← same caveat**
- fill_08: Laid-back syncopated fill (Ringo-style) **← same caveat; hits on 3-a, 4-e, 4-a**
- fill_09: Metric displacement, 2 bars (Tony Williams-inspired; dotted-quarter groupings over 4/4)

### Jazz patterns (3)
- jazz_01: Swing ride (spang-a-lang) with hi-hat pedal 2-4
- jazz_02: Straight ride (modal/cool) with hi-hat pedal 2-4
- jazz_03: Brush-like ghost snare

## Technical specs
- Standard MIDI File Type 0
- 480 ticks per quarter note
- GM channel 9 (displays as 10)
- Default tempo 120 BPM
- Velocity: Full=100, Accent=110, Medium=85, Light=65, Ghost=50, Flat/Barrett=90

## Broader context

This toolkit is part of a larger music production workflow. Dan also maintains a MIDI drum library indexer (separate repo, built with Claude Code) for querying an ~800K pattern collection by time signature and rhythmic characteristics. The toolkit serves a different purpose: it's a small, curated set of building blocks for fast scratch-track assembly, not for discovery. The two are complementary — the toolkit patterns could eventually serve as reference points for similarity search in the larger library.

Dan's DAW is REAPER. His typical workflow will be: find or build a pattern → import into REAPER → drag notes around in the MIDI editor to customize.
